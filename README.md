# Xiaozhi ESP32-C3 Custom – Arsiparis Cimahi

Custom firmware Xiaozhi AI berbasis **ESP32-C3 Super Mini 4MB** dengan tambahan:

- OLED SSD1306 128×64
- Microphone INMP441
- MAX98357A I2S amplifier
- DHT11 untuk membaca suhu dan kelembapan
- 2 relay aktif HIGH
- Relay Lampu
- Relay Kipas
- Tombol PTT / Push-to-Talk
- Bahasa Indonesia
- Wake Word: **Hi, Jason**
- Startup branding:
  **CREATED BY ARSIPARIS XIAOZHI CIMAHI**

Project ini dibuat menggunakan source resmi Xiaozhi ESP32 dan ESP-IDF 6.1.

---

## Hardware

### Mikrokontroler

**ESP32-C3 Super Mini 4MB**

### Audio Input

**INMP441 I2S Microphone**

### Audio Output

**MAX98357A I2S Amplifier**

### Display

**OLED SSD1306 128×64 I2C**

### Sensor

**DHT11**

Membaca:

- Temperatur
- Kelembapan

### Output

2 buah relay aktif HIGH:

1. Lampu
2. Kipas

### Input

1 tombol:

**PTT / Push-to-Talk**
